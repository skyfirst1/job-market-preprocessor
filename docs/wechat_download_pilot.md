## 最低风险手动单篇流程与准入门槛

现阶段可完成的最低风险操作是：离线登记用户明确指定的一条文章 URL，不解析或打开该 URL；阅读本报告；将真实试采保持阻断。用户允许自动化打开文章并要求保留监督窗口，不会补足后台请求控制证据，本次不得因此打开微信页面或启动工具。

只有以下条件全部有可复核证据，才可由主线程重新评估单篇试采；这不是当前可执行指令，也不会自动扩展既有授权：

1. 获得可信、可审计的单篇实现与分发对应证据；确定运行时不会读取账号凭据、自动登录或捕获密钥。
2. 在发送前可强制执行实际请求总量预算；覆盖重定向、重试、所有子资源和后台线程。仅有入口预算时仍阻断。
3. 确认历史列表、账号探测、合集、评论、媒体、剪贴板监听、后台轮询、定时抓取和远程回退全部关闭；确认不会加载持久化旧任务。官方现有 URL 参数不能提供这项确认。
4. 若满足前述条件并获准实际访问，只使用用户指定的一条单篇 URL、一个任务和已核实的纯文本保存选项；保持监督窗口，记录每次请求的原因和预算扣减，日志不得含 cookie、密钥或敏感 URL 查询参数。
5. 不获取公众号 ID、不获取凭据、不批量、不导出统计、不进入合集、不进行故障恢复回退。出现验证、登录要求、限流、异常后台请求、无法计量、超时或取消未确认，立即阻断，不自动重试；结束后确认无后台任务才报告结果。
